# Fluxo Fácil — Micro SaaS financeiro

MVP funcional de um controle financeiro extremamente simples para autônomos.

## O que já funciona
- Dashboard com saldo, entradas, saídas e quantidade de lançamentos
- Cadastro de entradas e despesas
- Categorias
- Lista de transações
- Exclusão individual e limpeza total
- Dados salvos no navegador via localStorage
- Assistente inteligente local com análises baseadas nos números cadastrados
- Interface responsiva para celular

## Como testar
Abra `index.html` em um navegador.

## Próxima versão para virar SaaS real
- Login/cadastro de usuários
- Banco de dados (ex.: Supabase)
- Backend/API
- IA via API para respostas mais naturais
- Assinaturas recorrentes (ex.: Mercado Pago/Stripe)
- Exportação PDF/Excel
- Lembretes de contas
- Dashboard mensal
- Multiempresa/MEI
